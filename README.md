### Logothea (구 EarningWhisperer) · 2026.03 ~ 2026.10
미국 기업 어닝콜을 실시간 자막과 한국어 번역으로 보여 주고, 경영진 발언을 직전 분기 발언과 대조하는 데스크톱 앱입니다.
4인 팀 졸업작품에서 Spring Boot 백엔드, 어닝콜 질의응답 서비스, Electron 데스크톱 앱, 서버 인프라를 맡았습니다.

**어닝콜 질의응답 (RAG)**
- 콜을 들으며 던진 질문에, 질문 시점까지 나온 발언과 그 전에 발행된 자료만 근거로 답하는 서비스를 FastAPI로 따로 만들었습니다. 질문 분류 → 근거 수집 → 답변 생성 → 인용 검증 4단계이고, 답에 붙은 인용 표시가 실제 근거를 가리키는지, 인용한 문장의 수치가 원문에 있는지 코드로 확인합니다
- 60문항 평가 하네스를 만들어 응답 상태·근거·시점 위반·지연·비용은 코드로, 정답 요점과 인용 정밀도는 LLM 채점으로 측정했습니다

**실시간 팩트체크**
- 월마트 콜 24문장으로 팩트체크를 실측하니 "모순" 판정 4건이 모두 오판이었습니다. 근거 기사를 600자로 잘라 넣어 검증할 숫자가 잘려 나간 것이 원인이었고, 상한을 4,000자로 올리고 지표·주체·회계기간이 모두 같을 때만 모순으로 판정하게 바꿔 오판을 없앴습니다

**백엔드**
- 주문을 대기 상태로 먼저 저장하고 체결 결과를 비동기 콜백으로 확정하는 구조라, 늦거나 겹치거나 위조된 콜백이 정합성을 깨뜨릴 수 있었습니다. 상태 변경은 도메인 메서드로만 허용하고, 행 단위 비관적 락과 콜백 소유자 검증을 넣은 뒤 예외 상황을 단위 테스트 30여 개로 고정했습니다
- 외부 종목 API를 DB 캐시와 분기 1회 동기화로 바꿔 호출을 연 약 16회로 줄이고 조회 응답을 10ms 미만으로 유지했습니다

`Java 17` `Spring Boot` `MySQL` `Redis` `WebSocket/STOMP` `Python` `FastAPI` `OpenAI API` `Electron` `AWS EC2` `Docker`

### PI-LOT · 2025.09 ~ 2025.12
임베디드 AI 과목 4인 팀에서 표지판 인식과 주행 구조를 맡았습니다. 제4회 매치업 심화과정 경진대회 실무보고서 부문 우수상을 받았습니다.

- YOLOv8 2단계(영역 탐지 → 7종 분류) 표지판 인식을 만들었습니다. 분류 모델 학습 데이터를 직접 모아 1,274장에서 4,394장으로 늘렸고, 탐지 모델은 입력 크기와 옵티마이저를 바꿔 mAP50-95를 0.754에서 0.919로 올렸습니다
- 추론이 조향을 막지 않도록 주행과 추론을 별도 스레드로 나누고, 인식 결과를 Lock으로 보호한 공유 상태로 넘겨 추론 중에도 조향 주기를 유지했습니다

`Python` `OpenCV` `YOLOv8` `Raspberry Pi`
